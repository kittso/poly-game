💡 Master's Tip (Remainder Theorem)

To find the remainder when f(x) is divided by (x - c), you don't need Long Division! Just substitute x = c into the polynomial. The remainder is simply f(c)!

🔒 A locked chest blocks your way! To find the hidden key (the remainder), solve:

Find the remainder when
f(x) = x3 + 3x2 - 2x + 4
is divided by x - 2

(Hint: Substitute x = 2 into f(x) and calculate!)

💡 Master's Tip (Factor Theorem)

If f(c) = 0, then (x - c) is a Factor of f(x) (meaning it divides perfectly with 0 remainder). If f(c) isn't 0, it's NOT a factor!
